# AI 코딩 보조 도구 사용 내역과 활요 이유 정리

## 커밋 메시지

기본 프로젝트 구성의 첫 커밋 메시지는 PyCharm의 GitHub Copilot으로 작성했다. 스테이징된 변경을 보고 메시지를 제안받게 해서, 추가된 파일 범위를 직접 요약하지 않으려고 사용했다.

## 코드 자동완성

에디터에서 코드를 일부 적으면 이어지는 구현을 채워 주는 GitHub Copilot 자동완성도 사용했다. 반복되는 구문과 함수 본문을 처음부터 전부 치지 않으려고 사용했다.

## 클래스, 함수, 변수 이름

클래스, 함수, 변수 이름은 AI 코딩 보조 도구로 만들었다. 교육 소개와 신청에 쓸 이름을 하나씩 새로 짓지 않고, 제안된 이름을 도메인에 맞게 고르려고 사용했다.

## 생성·수정 시각 믹스인

`created_at`, `updated_at`을 `TimeMixinModel`로 묶는 코드는 Grok Build로 작성했다. 교육과 신청 모델에 같은 시각 필드를 반복하지 않으려고 사용했다.

## URL 패턴 타입 주석

`configs/urls.py`의 `urlpatterns` 타입 주석은 Grok Build로 작성했다. `ty`가 `+=` 양쪽 리스트 원소 타입을 다르게 보아 실패한 검사를 맞추려고 사용했다.
